# SVG compatibility

Photolisa supports an intentionally bounded editable SVG subset. Open, drag/drop, and file picker use the same `SvgImporter` boundary. SVG export is generated by `SvgExporter`, not browser DOM serialization.

| Feature | Import | Export |
| --- | --- | --- |
| Paths, rectangles, circles, ellipses, polygons, lines | Native vector layers; original coordinates and path data retained | Native SVG geometry |
| Groups and paint order | Native nested groups in SVG paint order | Nested `<g>` elements in paint order |
| Fill, stroke, width, layer/paint opacity | Presentation attributes, inline styles, and simple class rules in `<style>` | SVG attributes |
| Transforms | `matrix`, `translate`, `scale`, and simple `rotate` stored as affine matrices | Affine matrix plus editor transform |
| `viewBox` | Stored in metadata and mapped through an editable wrapper group | Equivalent `0 0 width height` viewBox with wrapper transform |
| Existing raster layers | SVG `<image>` input is skipped and reported | Embedded as PNG data URIs |

SVG import resolves simple `.class` and `path.class`-style selectors (also tag-qualified classes for the other supported shapes and groups). Rules are applied in source order with tag-qualified class specificity; inline styles override class rules, and class rules override presentation attributes. Class styling becomes ordinary editable layer paint and opacity values; the original stylesheet text is not retained. Complex selectors, unsupported declarations, and stylesheet MIME types are reported as skipped. At-rules, URL functions, external references, and unsafe CSS are rejected. This is not a general CSS cascade implementation.

SVG import rejects DTDs/entities, scripts, foreign objects, event attributes, `href`/XLink, URL-valued attributes, and external resource references. It does not attach untrusted markup to the page. Unsupported elements such as text, gradients, filters, masks, clips, `<use>`, and embedded images are **skipped with compatibility warnings**, not silently flattened. Unsupported transform syntax is rejected. Unsupported attributes and inline CSS declarations are reported as skipped. SVG export rejects non-normal blend modes, masks, and enabled adjustments rather than silently discarding them; PNG export can be used when those effects are required.

Limits: 8 MiB SVG source text, 256 KiB per stylesheet, 512 class rules total, 10,000 visited supported elements, 64 levels of nesting, 1,000,000 characters per path or polygon, 16,384 pixels on either axis, and 67,108,864 document pixels. Pixel dimensions are supported; percentage, physical-unit, and CSS-sized roots are not. Default centered `meet` and `preserveAspectRatio="none"` are supported. Other alignment modes use centered fit with a warning. Nested `<svg>` viewports are skipped with a warning. Elliptical rounded rectangle corners and even-odd self-intersecting paths may differ in Pixi preview; full-resolution Canvas export and serialized SVG retain their paint/geometry values. This is not full SVG specification compatibility.
